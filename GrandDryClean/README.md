# GRAND DRY CLEAN — لوحة الإدارة

## الصفحات الرئيسية
- `dashboard.html`: بوابة أقسام الإدارة، وتعرض شعار GRAND DRY CLEAN الرسمي.
- `gm.html`: لوحة إدارة الأصناف والأسعار والأقسام والفروع والبيانات الأساسية.
- `index.html`: صفحة العميل الرئيسية.
- `order.html`: صفحة الطلب.
- `customer-account.html`: صفحة حساب العميل.

## ملفات الهوية والتصميم
- `assets/grand-dry-clean-logo.png`: الشعار الرسمي المستخدم في لوحة الإدارة.
- `css/management-home.css`: تصميم بوابة أقسام الإدارة وألوان الهوية.
- `css/gm.css`: تصميم لوحة الإدارة الداخلية.
- `BRAND-IDENTITY-AR.md`: دليل الألوان والاستخدام البصري المعتمد.

## المصادقة والبيانات
- تستخدم صفحات الإدارة إعدادات Supabase الموجودة في `../assets/config.js`، ويعمل `js/session-guard.js` على التحقق من هوية الحساب وصلاحياته.
- بعض عمليات إدارة الأصناف والأقسام ما زالت تعدّل بيانات العرض داخل الصفحة الحالية فقط، وبيانات الفروع وقائمة الأكثر طلبًا تُحفظ محليًا على الجهاز. هذه العمليات لم تُربط بالكامل بعد بعمليات الكتابة إلى Supabase.
- صورة الصنف تُعرض محليًا ولا يتم رفعها إلى GitHub أو Supabase من النموذج الحالي.
- لا تضع مفاتيح سرية أو بيانات اعتماد داخل ملفات الواجهة.
