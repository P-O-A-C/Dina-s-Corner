# GRAND DRY CLEAN — لوحة الإدارة

## الصفحات الرئيسية
- `dashboard.html`: بوابة أقسام الإدارة، وتعرض شعار GRAND DRY CLEAN الرسمي.
- `gm.html`: لوحة إدارة الأصناف والأسعار والأقسام والفروع والبيانات الأساسية.
- `index.html`: صفحة العميل الرئيسية.
- `order.html`: صفحة الطلب.
- `customer-account.html`: صفحة حساب العميل.

## ملفات الهوية والتصميم
- `assets/grand-dry-clean-logo.png`: الشعار الرسمي المستخدم في لوحة الإدارة.
- `css/management-home.css`: تصميم بوابة أقسام الإدارة وألوان الهوية.
- `css/gm.css`: تصميم لوحة الإدارة الداخلية.
- `BRAND-IDENTITY-AR.md`: دليل الألوان والاستخدام البصري المعتمد.

## المصادقة والحفظ
- تستخدم لوحة الإدارة إعدادات Supabase الموجودة في `../assets/config.js`، ويعمل `js/session-guard.js` على التحقق من هوية مدير المغسلة أو مدير POAC.
- لوحة `gm.html` تحفظ الأصناف والأسعار والأقسام والفروع والاختيارات المميزة وبيانات النشاط في جداول مستقلة تبدأ أسماؤها بـ `gdc_`.
- شغّل `GDC-MANAGEMENT-SUPABASE-SETUP.sql` مرة واحدة في SQL Editor قبل استخدام الحفظ. الجداول مستقلة عن جداول Dina's Corner حتى لا تختلط بيانات المشروعين.
- صور الأصناف تُضغط ثم تُرفع إلى Storage bucket باسم `gdc-service-images`.
- صفحة الطلب تقرأ الخدمات النشطة من جداول GRAND DRY CLEAN نفسها؛ لذلك تظهر تغييرات الأصناف والأقسام بعد حفظها وتحديث الصفحة.
- لا تضع مفاتيح سرية أو بيانات اعتماد داخل ملفات الواجهة.
