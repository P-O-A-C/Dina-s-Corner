تعديل لوحة إدارة الأقسام – GRAND DRY CLEAN

الملفات التي يتم استبدالها فقط:
1) GrandDryClean/gm.html
2) GrandDryClean/js/gm.js
3) GrandDryClean/css/gm.css

ما الذي تغير؟
- إظهار بطاقة مستقلة باسم «مكواة فقط» داخل إدارة الأقسام.
- قراءة عدد أصناف الكي من جدول gdc_ironing_prices.
- احتساب قسم الكي ضمن إجمالي عدد الأقسام في لوحة الإدارة.
- إبقاء قسم الكي خارج قوائم تصنيف أصناف الغسيل والتنظيف العادية، لأنه يُدار من جدول أسعار مستقل.
- تحديث أرقام ملفات CSS وJavaScript لمنع استخدام النسخة القديمة من ذاكرة المتصفح.

طريقة التركيب:
ارفع الملفات الثلاثة إلى نفس المسارات داخل مشروع GitHub واستبدل الملفات الحالية.
لا يحتاج التعديل إلى تشغيل SQL جديد إذا كان جدول gdc_ironing_prices منشأ بالفعل.
إذا تعذر قراءة جدول أسعار الكي، ستظل بطاقة «مكواة فقط» ظاهرة، لكن عدد الأصناف سيظهر كقائمة مستقلة دون رقم.
