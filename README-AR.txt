تعديل إدارة الأقسام – GRAND DRY CLEAN

الملفات البرمجية المعدلة فقط داخل الحزمة:
- GrandDryClean/gm.html
- GrandDryClean/js/gm.js
- GrandDryClean/css/gm.css
- GrandDryClean/order.html
- GrandDryClean/js/order.js
- sw.js

ما تم تعديله:
1) إزالة شارة GRAND DRY CLEAN أعلى لوحة الإدارة.
2) إزالة شريط رسالة حالة قاعدة البيانات الأخضر من واجهة الإدارة.
3) إضافة زر تعديل وزر حذف لكل قسم خدمة عادي.
4) جعل تعديل اسم قسم الكي المستقل وحذفه يعملان كذلك، مع تحديث الاسم في صفحة العملاء.
5) حذف قسم الكي يخفيه وأسعاره من صفحة العملاء مع الاحتفاظ ببيانات أسعار الكي في قاعدة البيانات (تعطيل is_active بدل الحذف النهائي).
6) لا يمكن حذف قسم خدمة عادي طالما توجد أصناف مرتبطة به؛ انقل أصنافه أولاً حتى لا تبقى أصناف بلا قسم.

مهم: شغّل ملف GDC-IRONING-CATEGORY-CONFIG.sql مرة واحدة من Supabase SQL Editor قبل تجربة تعديل أو حذف قسم مكواة فقط. هذا ينشئ إعداداً صغيراً لحفظ اسم القسم وحالة ظهوره.
ثم ارفع الملفات الستة إلى نفس المسارات في GitHub.
