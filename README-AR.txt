GRAND DRY CLEAN — تحديث الفروع وربط صور المفروشات ووسيلة الدفع Flash

محتويات الحزمة:
- GrandDryClean/index.html وملفات customer.js / customer.css: عرض فرعي كارفور وأمام شبانة بروابط الخرائط التي أرسلتها، وإظهار عنوان كل فرع، وإضافة Flash إلى وسائل الدفع.
- GrandDryClean/order.js وملفات الصور: ربط صور المفروشات الثمانية مباشرة حسب اسم الصنف، مع صورة السجاد الموجودة بالمشروع.
- GDC-UPDATE-BRANCHES-FURNISHINGS-AND-FAST-SERVICE.sql: حفظ روابط الفروع وروابط الصور في Supabase، وإضافة «خدمة سريعة +30%» كخدمة مستقلة في قائمة الخدمات.
- sw.js: تحديث رقم الكاش وإضافة الصور الجديدة إلى قائمة ملفات الموقع.

طريقة التطبيق:
1) ارفع الملفات والمجلدات بنفس المسارات الموجودة داخل ZIP إلى جذر مستودع poac على GitHub، مع استبدال الملفات التي لها نفس الأسماء.
2) شغّل ملف SQL مرة واحدة في Supabase SQL Editor. تشغيله مرة أخرى آمن؛ لا يضيف أصناف مفروشات مكررة.
3) انتظر نشر GitHub Pages، ثم افتح الصفحة مع تحديث كامل Ctrl+Shift+R. تم تغيير رقم service worker cache لإجبار المتصفح على تحميل النسخة الجديدة.
