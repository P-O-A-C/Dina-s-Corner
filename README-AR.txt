تعديل GRAND DRY CLEAN: حذف زر الجرس وإظهار الفروع في الصفحة الرئيسية

الملفات:
- GrandDryClean/index.html: إزالة زر الجرس من الهيدر وتحديث إصدار CSS/JS.
- GrandDryClean/css/customer.css: إزالة تنسيق زر الجرس.
- GrandDryClean/js/customer.js: تحميل الفروع النشطة من public.gdc_branches وعرض الاسم والعنوان والهاتف ورابط الخريطة.
- sw.js: تحديث اسم كاش Service Worker حتى لا تبقى نسخة قديمة من الصفحة والسكريبت.

طريقة التركيب:
استبدل الملفات في المسارات نفسها داخل GitHub Pages.

متطلبات ظهور الفروع:
1) يجب أن تكون الفروع مضافة في public.gdc_branches وقيمة is_active = true.
2) يجب أن تسمح سياسة القراءة العامة SELECT لدور anon بقراءة الصفوف النشطة.
3) صفحة العملاء تستخدم إعدادات Supabase الموجودة في assets/config.js.

إذا لم توجد فروع نشطة فستظهر رسالة تفيد بأنه سيتم إضافة بيانات الفروع قريبًا.
إذا رفض Supabase القراءة فستظهر رسالة تعذر تحميل الفروع، ويظهر سبب الخطأ في Console.
