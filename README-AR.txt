تعديل زر «مكواة فقط» كقسم مستقل

السبب الذي تم إصلاحه:
كانت شبكة الخدمات تحتفظ بـ display:grid من CSS حتى بعد ضبط خاصية hidden عليها، لذلك كانت خدمات المفروشات تظل ظاهرة مع أسعار الكي.

الملفات المعدلة فقط:
1) GrandDryClean/order.html
2) GrandDryClean/css/order.css
3) sw.js

طريقة التركيب:
استبدل الملفات الثلاثة في نفس المسارات داخل المشروع، ثم ارفعها إلى GitHub Pages.
بعد التحديث، اضغط «مكواة فقط» من صف الأزرار العلوي؛ ستظهر أصناف الكي وصورها وأسعارها فقط. وعند الضغط على «مفروشات» أو «غسيل وكي» سيظهر محتوى ذلك القسم فقط.

لا يتضمن هذا التعديل أي تغيير على قاعدة البيانات أو الأسعار أو الصور.
