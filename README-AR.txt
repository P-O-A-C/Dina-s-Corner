GRAND DRY CLEAN — ربط صور أصناف المفروشات

محتويات الحزمة:
- 8 صور PNG منفصلة، كل صورة لصنف مفروشات واحد.
- GDC-LINK-FURNISHINGS-IMAGES.sql لربط روابط الصور بالأصناف الموجودة بالفعل في Supabase.

ترتيب التنفيذ:
1) ارفع مجلد GrandDryClean/assets/products/furnishings/ الموجود داخل الحزمة إلى GitHub في نفس المسار.
   يجب أن تبقى أسماء الصور كما هي.
2) بعد ظهور الملفات على GitHub Pages، افتح Supabase > SQL Editor.
3) شغّل GDC-LINK-FURNISHINGS-IMAGES.sql مرة واحدة.
4) حدّث صفحة GRAND DRY CLEAN تحديثًا كاملًا (Ctrl+Shift+R).

مهم:
- السكربت يحدّث image_url فقط للأصناف الموجودة بالفعل داخل قسم «مفروشات».
- لا يضيف أصنافًا جديدة ولا يغيّر الأسعار أو الأسماء أو الأقسام.
- كل صورة من الصور الثماني ملف مستقل بمقاس 320×320 بكسل.
- خدمتا السجاد «متر السجاد العادي» و«متر السجاد شاج أو فرو» تستخدمان مؤقتًا صورة السجاد العامة الموجودة بالفعل في المشروع: GrandDryClean/assets/products/carpet.jpg.
- لا يلزم تعديل HTML أو JavaScript؛ صفحة الخدمات تعرض image_url الموجود في قاعدة البيانات بالفعل.
